INTERVIEW QUESTION
------------------

1. brute force find the second largest
go back and find second largest

for (i=n-2;i>=0;i--){
    if(arr[i]!=largest){
        secondl=arr[i];
        break;
    }
    return;
}



2. 1 pointer method
find largest... and repeat till you find second laregest

slarge=-1
for(i=0;i<n;i++){
    if(arr[i]>slarge && arr[i]<largest){
        secondl=arr[i];
        break;
    }

    return secondl;
}

TC- O(2n)


3. OPTIMAL APPROACH (2 pointer method)

    1. one pointer points to largest
    2. pointer compares to largest but points to second largest
largest = arr[0];
secondl=-1;
for (i=1;i<n;i++){
    if (arr[i]>largest){
        largest=arr[i];
    }
    if(arr[i-1]>secondl && arr[i-1]!=largest){
        secondl=arr[i];
    }
}
