optmized version - 2 pointer approach

duplicates(arr, n){
 i=0;
 for(j=1;j<n;j++){
    if(arr[j]!= arr[i]){
        arr[i+1]=arr[j];
        i++;
    }
 }  
 return (i+1);

}  
    
TC- O(N)
SC - O(1)
